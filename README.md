# DeividXOfertas

Página de ofertas (link na bio) com botão para o canal de WhatsApp.

## Estrutura
- `index.html` - página principal
- `css/style.css` - estilos
- `assets/logo.webp` - logo DeividXOfertas
- `.nojekyll` - evita processamento do Jekyll no GitHub Pages

## Publicar no GitHub Pages
1. Crie um repositório e envie todos os arquivos desta pasta para a raiz.
2. Em Settings > Pages, escolha a branch `main` e a pasta `/ (root)`.
3. A página fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Onde editar
- Link do WhatsApp, produtos e textos: `index.html`
- Cores: variáveis no início de `css/style.css`
